# FREE KICK 3D ver.c.4 — CLAUDE.md

> `games/free-kick/c4/` は Claude 版 ver.c.4 のソース（公開URL `/tomzo-arcade/free-kick/ver.c.4/`）。FREE KICK LAB 全体の仕様は `../CLAUDE.md`、アーケード共通のルールはリポジトリ直下の `CLAUDE.md`。
> 旧リポジトリ `Tomuzou/soccer-app` の `claude-c4` ブランチ（37a5e8a）から 2026-10-12 に移した。それ以前の履歴はそちらに残っている。

ver.c.3（5d2df35）から Claude Code が独自設計で発展させた版。ステージ（α〜δ）・γ の球数制限・δ の風・物理モデルの基本は ver.c.3 と共通で、`../CLAUDE.md` の該当節とほぼ同じ（アイテム・保存・画面レイアウトなどは下記のとおり別物）。

## ビルドと公開

- 公開されるのは `../public/ver.c.4/` の凍結ビルド。アーケードの通常の `npm run build` はそれをコピーするだけで、このソースはビルドしない
- 直したら `games/free-kick/` で `npm run build:c4`（`scripts/build-c4.mjs`）。型チェック → base `/tomzo-arcade/free-kick/ver.c.4/` でビルド → `public/ver.c.4/` の `index.html` と `assets/` を置き換える。結果をコミットすれば公開される
- 開発サーバーは `npm run dev:c4`（`/` で開く）
- 依存ライブラリは `games/free-kick/` と共有（three 0.169 / cannon-es 0.20 / React 18 / Vite 5）。バージョンを上げると ver.c.4 の出力も変わるので注意
- 移した直後の再ビルドは、旧ビルドと js・css の中身がバイト単位で一致した（本体 js のファイル名ハッシュだけ変わった）

## ver.c.4 固有の仕様

- **スキルボール**（`src/game/items.ts`、`Game.setItem`）：倍率ではなく球質を変える。照準中のみ選択可、モード開始・メニュー復帰でノーマルに戻る
  - 🌀ナックル：無回転（カーブ無効）＋2周波の揺れ加速度（`KNUCKLE_ACC_X/Y`、ショットごとにランダム位相、速度と高さでフェード）
  - ⤵️ドライブ：進行方向に直交する水平軸のトップスピン（`DRIVE_TOPSPIN`）でマグヌス力を下向きに
  - 🔥キャノン：初速1.45倍・抗力0.75倍・カーブ0.35倍
  - 🪃ブーメラン：カーブ3.2倍。マグヌス力を飛行0.6秒かけて0.25→1.5倍へ強め（`BOOMERANG_*`）、序盤はまっすぐ・後半に急激に曲がる。カーブ0で選ぶと0.6を初期設定
  - 👻ゴースト：固定の壁（`wallBodies`＝move/track なしの障害物）だけ `collisionResponse=false`。`resetBall` で戻す
- **物理**：`simulate` で 1/120 秒の固定サブステップ。毎ステップ `applyBallForces`（抗力・マグヌス・ナックル・転がり）→ `world.step` → ポスト／ゴール面判定
- **カーブの符号**：ver.c.3 では正のカーブが左へ曲がっていたため、`shoot` でスピンの符号を反転（正=右）
- **記録**（`src/game/records.ts`、キー `free-kick-3d.c4`。公開中の保存データが消えるので変えない）：ステージごとの最少球数と👑（スキルボールを一度も使わずにクリア＝`GameState.stageItemUsed` が false）、フリープレイの最高連続ゴール、ミュート・弾道表示。保存できなくてもプレイ継続
- **UI**：タイトル → ステージ選択（α〜δ タブ×10、全解放）、HUD に連続ゴール・ステージ自己ベスト、右上にメニュー／🔊／弾道／蹴り直し、下部にスキルバー（PC・横長は左側縦並び、縦長は横一列）とメーター、キック後に球速 km/h、クリア画面に記録更新と「もう一度」
- **見た目**（`src/game/scenery.ts`）：ACES トーンマッピング＋sRGB テクスチャ、空ドーム（シェーダー）と半球光・太陽光（影はプレー範囲に絞る）、10m タイルの刈り込み芝、32パネル（五角形12・六角形20）を球面で塗り分けたボール＋縫い目バンプ＋クリアコート、細目ネット、金属ポスト、観客入りの段々スタンド3面・屋根・照明塔・発光広告ボード、壁は選手の列・キーパーは人型（当たり判定は従来の箱のまま）
- **キー操作**：←→ カーブ / 1-6 球質 / R 蹴り直し / M 音 / T 弾道 / Esc 戻る
- **他バージョンへのリンク**：`BASE_URL` から `ver.c.N/` を除いた公開ルート（`/tomzo-arcade/free-kick/`）を基準にする。入れ子のリダイレクトスタブは不要
