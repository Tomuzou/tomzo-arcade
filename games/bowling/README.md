# BANK BOWLING — GIMMICK BOWLING v0.3

高台から投げ、曲面バンクでUターン。帰りの軌道を読んでピンを倒す、TOMZO ARCADE の3Dボウリングです。

## 遊び方

1. 盤面上の光る輪のボールをつかみ、矢印と反対に引っぱって離すと投球。引く向きで方向、長さで強さが変わります。指をボールへ戻すかEscでキャンセルできます。
2. スピンはバー、立ち位置は左右ボタンで調整。ボールがピンへ近づくと自動で拡大します。投球中のボタンで2倍速にできます。
3. 白1点・青5点・赤100点。規定投球数以内に目標点を取るとクリア。
4. 残ったピンは次の投球へ引き継ぎます。失敗しても何度でも再挑戦できます。

全倒しまたは1投クリアで3つ星、最終投の前にクリアで2つ星、最終投のクリアで1つ星。自己ベストと星はブラウザに保存します。
「コース」ボタンから好きなステージを選べます。練習モードは球数無制限・記録対象外です。コース一覧を閉じれば、PC・スマホとも盤面が画面の大部分を占めます。「視点」でプレイ・全体・ピン拡大を切り替えられます。

| コース | 特徴 |
| --- | --- |
| スター・バンク | 星形65ピンと曲面バンク |
| スイング・ゲート | 帰り道を横切る可動ゲート |
| バンパー・クラブ | ダイヤ型バンパーで反射 |
| ツイン・ターゲット | 左右2群のピン、赤ピン2本 |
| 100ピン・フェス | 回転アームと100本のピン |
| クラシック・レーン | 10ピンを2投で全倒し。1本10点 |

キーボード：Space 投球・次の球・早送り、←→ 角度、↑↓ 強さ、R やり直す、V 視点切替。
ボールをフォーカスすると矢印キーで調整し、Enterでも投球できます。スピンバーや通常のボタンにフォーカスがある間は、そのコントロールの標準キー操作が優先されます。

## 開発・確認

リポジトリ直下で実行：

```sh
npm install
npm run dev:bowling
npm test -w @tomzo-arcade/bowling
npm run build -w @tomzo-arcade/bowling
npm run test:browser -w @tomzo-arcade/bowling
npm run build
npm run verify
```

ブラウザテストはローカルの Chrome を使用します。PCのマウスドラッグと390px幅の実タッチイベントによる投球、クリア・記録・練習・再投球・キャンセル・リサイズ・キーボード操作を検証します。
ユニットテストも実ゲームと同じ cannon-es の床・ボール・ピンを使い、Uターン、赤ピンへの到達、ストライク、可動ゲート通過を検証します。

ステージの追加・調整は `src/data/stages/courses.json`、物理定数は `src/core/constants.ts`。
Three.js の InstancedMesh でピンを描画し、cannon-es を1/120秒の固定刻みで進め、描画を補間します。

参考：[VS嵐 バンクボウリングの公式説明](https://www.fujitv.co.jp/vs_arashi/attraction/attraction.html)。
高台・曲面でのUターン・星形配置・色別得点を参考にした独自のシングルプレイゲームです。番組の画像・ロゴ・音源は使用していません。

公開先は [TOMZO ARCADE](https://tomuzou.github.io/tomzo-arcade/) の `bowling/`。
公開には通常のリポジトリのデプロイ手順を使用します。
