# 🎳 GIMMICK BOWLING — 仕様書 v1.0

3Dボーリングゲーム。ステージクリア型の「ステージモード」と、自由に遊べる「フリープレイ」を搭載。
ステージが進むにつれて、障害物・100ピン・カーブレーン・坂道など**ゲームならではの特殊ギミック**が解禁されていく。

---

## 1. 技術スタック

| 項目 | 採用技術 | 理由 |
|------|---------|------|
| レンダリング | **Three.js** | 3D表現の定番。情報量が多くClaude Codeとの相性も良い |
| 物理エンジン | **cannon-es** | 軽量・npmで完結・Three.jsとの連携例が豊富 |
| ビルドツール | **Vite** | 高速な開発サーバー、設定ほぼ不要 |
| 言語 | **TypeScript** | 型があるとClaude Codeのリファクタが安定する |
| 状態管理 | 素のクラス設計(ライブラリ不使用) | ゲームロジック程度なら不要 |
| セーブ | `localStorage` | クリア状況・ハイスコアの永続化 |

> **Note:** 100ピンステージで物理演算が重い場合は Rapier (WASM製・高速) への移行を検討。ただしまずは cannon-es で始める。

## 2. ゲームモード

### 2.1 ステージモード
- ステージ1から順にクリアして解放していく
- 各ステージに「クリア条件」と「投球数制限」がある
- クリアで ⭐(1〜3個)を獲得。条件例: 規定投球数以内 / ノーミス / スペア以上
- クリア状況は localStorage に保存

### 2.2 フリープレイ
- 通常の10フレーム制ボーリング(公式ルール準拠のスコア計算)
- クリア済みステージのギミックレーンを選んで遊べる(解放要素)
- ハイスコア記録

---

## 3. コア操作(投球システム)

3段階の入力方式(タイミングゲージ式):

1. **位置決め** — ←→キー(またはドラッグ)で立ち位置を左右に移動
2. **角度決め** — 左右に振れる矢印をタイミングよく止める
3. **パワー&スピン** — ゲージでパワー決定 → 追加入力でスピン(カーブ)量を決定

- 投球後はボール追従カメラに切り替え
- ピンヒット時はスローモーション演出(任意/後回しOK)

## 4. 物理仕様

| 要素 | 値(初期案) |
|------|------------|
| ボール | 半径 0.108m、質量 6kg、球体コライダー |
| ピン | 高さ 0.38m、質量 1.5kg、円柱+αの複合コライダー(まずは円柱で簡易化) |
| レーン | 長さ 18m、幅 1.05m、低摩擦(オイルゾーン表現は摩擦係数の差で) |
| ガター | レーン両脇の溝。落ちたら無効 |
| ピン転倒判定 | ピンの傾き角が閾値(例: 45°)を超えたら「倒れた」扱い |

## 10. 技術的な注意点(ハマりポイント先回り)

1. **カーブレーンのコライダー**: cannon-es に曲面コライダーはないので、短いBox板を連結して近似する(`Lane.ts` でセグメント分割生成)
2. **100ピンの負荷**: ピンは倒れて静止したら `sleep` させる。描画は `InstancedMesh` を使う
3. **ピンの複合コライダー**: 最初は円柱1本で十分。リアルさが欲しくなったら球+円柱の複合に
4. **物理と描画の同期**: 固定タイムステップ(1/60s)で `world.step()`、描画側で補間
5. **スピン(カーブ)**: 本物のマグヌス力は複雑なので、「レーン摩擦×角速度で横力を加える」簡易モデルでOK
