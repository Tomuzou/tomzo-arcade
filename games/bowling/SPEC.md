# GIMMICK BOWLING / BANK BOWLING — 仕様 v0.3

## 現在のゲーム

1人用ステージチャレンジと球数無制限の練習。全6コースを最初から選択可能。
VS嵐のバンクボウリングに着想を得た、高台 → 曲面バンク → Uターン → ピンデッキという構成。
曲面は実際の物理コライダーで、ボールの進路をスクリプトで強制的に折り返しません。

| ID | ピン | 目標 | 上限 | 特徴 |
| --- | ---: | ---: | ---: | --- |
| star-bank | 65 | 115 pt | 3投 | 五芒星のピン配置 |
| swing-gate | 65 | 110 pt | 3投 | 横移動ゲート |
| bumper-club | 65 | 110 pt | 3投 | 反射用のダイヤバンパー |
| twin-stars | 30 | 210 pt | 3投 | 赤ピンが1本ずつある左右の島 |
| century | 100 | 145 pt | 4投 | 回転アームと密集ピン |
| classic | 10 | 100 pt | 2投 | 直線レーン、1本10点 |

バンクコースの得点は白1・青5・赤100。番組のチーム戦や全65本200点ルールとは異なり、倒したピンの点数を単純加算します。

## 状態と入力

`ready → rolling → between → ready`。クリア・投球数終了・全倒しでは `result` へ。
結果を閉じても「リザルトを見る」で再表示できる。やり直し／ステージ切替は現在の挑戦を破棄し、ピン・球数・タイマーを初期化する。

- ボールを直接ドラッグして投球。画面に投影した発射面の座標を逆変換し、引く方向から角度 −25〜30°、距離からパワー20〜100%を決める。PCとタッチは共通のPointer Eventsを使用。
- スライダーはスピン −3〜3だけ。立ち位置は左右ボタン。方向・強さはその場の矢印・数値・リングで確認できる。
- 14px未満／前向きのドラッグは投球しない。開始位置へ戻す、Esc、pointercancel、キャプチャ喪失、ウィンドウの非表示・フォーカス喪失、リサイズでキャンセルして元の狙いを復元する。
- キャプチャにより盤面外でも離せる。サイズ変更イベントより先にリリースが来ても、開始時との寸法比較で誤投球を防ぐ。
- 投球中は調整を無効化。投球ボタンは通常速度／2倍速の切替に変わる。
- キー：Space投球、←→角度、↑↓強さ、Rリセット、V視点。ボールのフォーカス中は矢印キー・Enter投球も使用可能。その他のフォーム・ダイアログ操作中はゲームのショートカットを実行しない。
- 停止・場外で落ち着いた後、または15秒の上限で投球終了。倒れたピンは次の投球前に除去。
- 全倒し／1投クリアは星3、最終投より前は星2、最終投クリアは星1。
- 練習は球数無制限。全倒しまで継続し、記録を更新しない。

## データと設計

- `src/data/stages/courses.json`：名前、説明、配置、目標、投球上限、初期調整値、障害物と動き。
- `StageManager`：JSONに従いレーン・ピン・障害物を生成。得点と転倒の管理。
- `surfaces.ts`：平面・48分割の円弧・発射坂のパラメータ生成。
- `LanePhysics.ts`：実ゲームとテストで共通の床・レールのコライダー。
- `Lane`：木目の床、連続した曲面、レール、台座、案内表示。
- `Ball`：球体ボディ。待機中は静的、投球時に動的。接地付近だけ簡易スピンの横力を適用。
- `Pin`：胴体円柱＋頭部球の複合コライダー。45°以上傾く／床下落下で転倒をラッチ。
- ピン描画は LatheGeometry と InstancedMesh。最大100体、sleep有効。
- `Obstacle`：静的バンパー／kinematic の移動・回転アーム。
- `Arena`：照明・影・縦横比に応じたカメラ。プレイ・全体・ピン拡大の3表示。プレイ表示ではボールがピンへ近づくと2倍に寄り、次の投球で戻す。ドラッグ中はカメラを固定する。
- `ThrowController` / `gesture.ts`：直接投球・入力のキャンセル・画面上の矢印と引っぱり線。物理エンジンのボールサイズやピン配置は変更しない。
- `Records`：`gimmick-bowling.bank-records.v1` にベスト点と最多星を保存。不正データや保存不可でもゲームを継続。
- `Sound`：Web Audio の合成効果音。ユーザー操作後に有効化し、ミュート可能。

物理は1/120秒固定。投球すり抜けを抑えるため旧仕様案の1/60秒から継続して細分化。
表示は前後の物理位置・姿勢から補間する。非表示タブでは時間を進めない。
投球終了時にピンを停止し、結果確定後に点数が変わらないようにする。

## 検証

`npm test`：実物理のUターン・赤ピン・ストライク・ゲート通過・バンパー・投球リセット・保存データ。
`npm run test:browser`：本番ビルドに対するPC／スマホの投球とUI操作。
レイアウト確認用の `tests/capture.mjs` は開発サーバーの5179番ポートを使用。
