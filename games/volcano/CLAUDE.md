# VOLCANO ROLL — 開発ガイド

TOMZO ARCADE の玉転がしゲーム。共通ルールはリポジトリ直下の `CLAUDE.md`。
ユーザーの「ターゲットマシン ボルケーノのように、玉を転がして穴や坂を避けながらゴールを目指す」という案から作ったオリジナルの盤面。

- Three.js + TypeScript + Vite。独立したページ `/tomzo-arcade/volcano/`。
- `src/stages.ts`：10コースのデータ。01〜05は穴・壁・ガウス型の坂、06〜10はギミックコース。ギミックは任意項目：`plateaus`（台地・スロープ。地形は台地の最大値を取る）、`pits`（蟻地獄）、`blackHoles`、`jumps`（ジャンプ台）、`warps`（2点を双方向でつなぐ）、`bumpers`。`clear` はゴール時の見出し。
- コースは配列の末尾に足す（記録はコースの番号で保存しているので、途中に挟むと記録がずれる）。
- `src/physics.ts`：1/120秒の固定刻み、坂の勾配、転がり・減衰・ブレーキ、壁衝突、穴／ゴールの線分スイープ判定。物理は描画から分離。`ball.impact` にその刻みの衝突速さを入れる（効果音用）。
  - 高さ：`ball.y`/`vy`/`air`。接地中は地形に沿い、地形が重力より速く落ち込む所（崖の縁）では飛び出す。登り途中で浮いても崖を越えないよう、飛び出す時の上向き速度は水平の速さの半分まで。空中は入力30%・坂の力なし、穴・蟻地獄・ゴールの判定なし、壁より高ければ越える。空中で崖の側面に当たったら跳ね返る。強く着地すると小さく跳ねる。
  - 勾配は `surface` の中心差分。結果は `fall`（穴）/`pit`（蟻地獄）/`blackhole`/`goal`。飲み込んだ地点の中心を `ball.trap`、ジャンプ・着地・ワープ・バンパーを `ball.event` に入れる。ワープは出口から離れるまで再突入しない（`warpLock`）。
- `src/scene.ts`：台のメッシュ・穴・坂・玉・斜面に沿う玉の影（空中では広く薄く）・明滅するゴールの輪。急斜面は岩色、蟻地獄は砂色。外枠は縁の地形より高くする。ギミックの見た目と動き（`animators`）。台地のあるコースはカメラを少し低くする。台の視覚的な傾きは演出。物理上の入力が転がる力を決める。
- `src/main.ts`：画面、入力、状態遷移、記録保存。矢印/WASD、Spaceでブレーキ、Rで最初から、Escで一時停止。スマホは長押しの画面ボタン。落下時は一番近い穴の中心へ玉を寄せながら沈める。ダイアログ表示中は Space/Enter のキーリピートを無視する（ブレーキを押したまま落下・ゴールしても、離した瞬間にボタンが押されない）。
- `src/tilt.ts`：任意で有効にするスマホ傾き入力。ユーザー操作からセンサー許可を要求、初回サンプル／開始／再開で基準設定。画面角度補正、2度の不感帯、約18度で最大入力、時間基準の平滑化。欠損値を無視し、センサー待機は5秒で終了。未対応・拒否時も方向ボタンを残す。HTTPSが必要。
- `src/sfx.ts`：WebAudio で合成する効果音（衝突・中継地点・落下・ゴール・ジャンプ・着地・ワープ・バンパー・ブラックホール）。音源ファイルなし。ON/OFF は上部ボタンで切り替え、`volcano-roll.sound.v1` に保存。
- 保存キー `volcano-roll.records.v1`。コース別の最短タイムだけを保存。ゴール時は前回ベストとの差、全コースのクリア後はメニューに合計ベストを表示。読み込み時は、コース数より大きい番号の記録を捨てる。失敗後の再挑戦はそれまでの時間を引き継ぎ、停止／メニュー／非表示中は時計を止める。
- 画面上部の「メニュー」「← ゲーム選択」は全状態で表示し、キーボードでもアクセスできるようにする。メニューはプレイを停止してコース一覧を表示。
- ハブへのリンクは `hubUrl(import.meta.env.BASE_URL)`。開発時はローカル全体プレビュー `http://127.0.0.1:4180/tomzo-arcade/` へ戻す（直下で `node scripts/desktop.mjs --serve-only` を起動）。

コマンド：`npm run dev` / `npm run build` / `npm test`。ビルド後に `npm run test:browser` で Chrome の操作・保存・一時停止・スマホ表示を確認（CIでは実行しない）。全体の確認はリポジトリ直下で `npm test`、`npm run build`、`npm run verify`。
物理を変えたら穴のすり抜け・壁衝突・坂・ブレーキ・各ギミックのテストと、全コースのルート検証（`tests/physics.test.mjs`。コースを足したらルートも足す）、実プレイを確認する。
