# VOLCANO ROLL

穴と坂のある台を傾け、玉を金色のゴールへ導く3D玉転がしゲーム。
全10コースを最初から選べます。01〜05は基本コースで、05「ボルケーノ」は火山の坂を登って頂上を目指します。
06〜10はギミックコースです。

| コース | ギミック |
| --- | --- |
| 06 ジャンプ台 | 緑の矢印に乗ると矢印の向きへ跳ぶ。空中は穴の上も越えられる |
| 07 蟻地獄 | すり鉢状の砂地。玉が重くなり、中心に落ちると食べられる |
| 08 ブラックホール | 渦を巻きながら遠くから引き寄せ、中心で吸い込む |
| 09 ワープとバンパー | 同じ色の輪どうしでワープ。赤いバンパーは強く弾き返す |
| 10 天空の段々畑 | 段差のある3D地形。スロープで登り、最上段へはジャンプ台で飛び移る。速いまま崖の縁を越えると飛び出す |

## 操作

| 操作 | キーボード | スマホ |
|---|---|---|
| 台を傾ける | 矢印 / WASD | 方向ボタンを長押し |
| 減速 | Spaceを長押し | BRAKEを長押し |
| 最初から | R | メニュー → 最初から |
| 一時停止・コース変更 | Esc | メニュー |

画面上部の「メニュー」と「← ゲーム選択」はプレイ中・落下中・結果画面でも表示されます。
「← ゲーム選択」で TOMZO ARCADE の一覧に戻れます。
開発時の戻り先には、直下で `node scripts/desktop.mjs --serve-only` を起動してください。

青い輪は中継地点。一度通れば、穴に落ちてもその地点から続けられます。
落下前の時間は引き継ぎます。一時停止中と再挑戦画面ではタイマーが止まります。
コース別ベストタイムをブラウザに保存します。

## スマホの傾き操作

「スマホの傾きで操作」を押し、許可画面が出たら許可します。
スマホを遊びやすい角度で持つと、その持ち方が基準になります。
左右・前後へ少し傾けて操作し、BRAKEで減速できます。
「傾きをリセット」で持ち方を変更できます。コース開始・再開時も現在の持ち方を基準にします。
縦・横画面に対応。画面の向きを変えたときは基準を取り直します。
許可されない／センサーがない場合は方向ボタンを使えます。公開ページのHTTPSで利用してください。

リポジトリ直下で `npm run dev:volcano`。本番は `npm run build` → `npm run verify`。
